# dsh-quake-alert · QuakeAlert

[English](./README.md) · [中文](./README.zh.md) · **日本語**

DeepSeek Harness（DSH）のプラグインです。DSH を使っている間に、**日本**と**世界**の地震・津波・気象災害をリアルタイムで受け取り、登録した地域としきい値に一致したときに、通知音・ページ内トースト・システム通知でお知らせします。

⚠️ **免責事項（先にお読みください）**：アラートデータは [P2PQuake](https://www.p2pquake.net/)、気象庁の公開 XML 電文、[EMSC](https://www.seismicportal.eu/)、[USGS](https://earthquake.usgs.gov/)、[NOAA](https://www.tsunami.gov/) が提供または転送するもので、いずれも公式の直接配信ではありません。緊急地震速報（EEW）の内容と配信品質は保証されません。本プラグインの通知は**あくまで参考情報**であり、避難の判断は必ず自治体などの公式発表に従ってください。本プラグインは DSH のページを開いている間だけ動作します。

## 主な機能

- **リアルタイム配信（日本）**：P2PQuake へ WebSocket で常時接続し、地震情報（551）・緊急地震速報 EEW（556）・津波予報（552）を受信します。EEW は気象庁の発表から P2PQuake の転送まで数百ミリ秒です。
- **リアルタイム配信（世界）**：EMSC の WebSocket で世界の地震を受信します。
- **日本の気象警報**：気象庁の公開 XML 電文から土砂災害・洪水・大雨・高潮を取得し、警戒レベル4以上のみ通知します。
- **中国大陸**：Wolfx が転送する CENC の地震警報と地震情報、および nmc.cn の大雨・地質災害の警報信号（オレンジ以上）に対応します。
- **米国とカナダ**：NWS の洪水警報と ECCC の降雨・洪水・高潮警報を、ブラウザから公式 API へ直接問い合わせます。
- **世界の地震と津波**：USGS の世界地震カタログと NOAA の津波 CAP 電文を、いずれも Host 側がポーリングします。
- **登録地域**：入口は 1 つだけです。まず国 / 地域を選び、次にその国の下位コントロールを展開します。日本 → 都道府県（任意で市区町村まで）、中国大陸 → 省 → 地級市 + 半径、その他の国 / 地域 → 都市リストまたは座標 + 半径。
- **半径は段階で指定**：ローカルのみ（約 30 km）/ 市とその周辺（約 100 km、新規登録時の既定）/ 広い範囲（約 300 km）。キロメートル数を直接入力することもできます。
- **しきい値は 1 つの表に**：1 行に 1 災種で、左のスイッチが通知するかどうか、右のしきい値がどの強さから通知するかを決めます。気象災害は境界が固定なのでスイッチのみです。
- **通知**：合成した通知音（音量調整可）と、ページが表示中はトースト、バックグラウンドではシステム通知。地震と EEW の見出しには震度が入ります。
- **取消・解除の通知**：通知済みの EEW が取消になったとき、または津波予報が解除されたときに、短い下降音でお知らせします。NWS の取消は VTEC の追跡番号で照合します。
- **サイレント時間帯**：毎日決まった時間帯は重要でない警報を鳴らしません。赤レベルは既定で貫通し、オフにもできます。
- **自動再接続**：指数バックオフ（1 秒 → 60 秒）。P2PQuake は約 10 分ごとに強制切断するため再接続は正常な動作です。接続が開かない場合と、接続後に無音になる場合の両方を検出して復帰します。
- **同じ地震は 1 回だけ**：同じ地震の複数発表は 1 回だけ通知し、震度が上がったときのみ再通知します。複数の機関が同じ地震を報じた場合は、先に到達したソースだけが通知します。
- **履歴**：直近 5 日間の処理記録 30 件。実際に鳴ったものと、そもそも判定できなかったものだけが残ります。
- **表示言語**：简体中文 / 繁體中文 / 日本語 / English。設定で切り替えると即時反映されます。データ源から来たテキストは原文のまま表示します。
- **設定のエクスポートとインポート**：設定を JSON ファイルに書き出し、別のマシンやブラウザで読み込めます。インポートは全体を置き換え、事前に現在の設定を自動でバックアップします。
- **このマシンに保存**：設定は DSH 経由で保存されるため、ブラウザやマシンをまたいで保持されます。ブラウザ側のコピーはミラー兼フォールバックです。
- **ソース状態**：サイドバー下部の状態ドットとホバー時の詳細、および「設定 → テストと診断」の受信件数・失敗回数・欠落・最終取得・上流の停更。
- **データソース切替**：本番（リアルタイム）とサンドボックス（2023 年の履歴を約 30 秒に 1 件再生）。
- **ローカル診断**：2 つのテストボタンがソース形式の電文をローカルで組み立て、実際のパーサーとマッチャーを通します。ネットワーク通信は一切発生しません。

## インストール

```sh
# GitHub から直接インストール
dsh plugin --profile web add github:MurasakiIzumi/dsh-quake-alert

# dsh web を再起動するとプラグインが有効になります
```

**アップデート**：パッケージを差し替えて `dsh web` を再起動します。Client 側（`client/`）だけの変更はページの再読み込みで反映されますが、`lib/` の変更には再起動が必要です。

## 使い方

1. **設定 → 災害警報** を開きます。
2. **登録地域** —— まず**国 / 地域**を選び、次にその国の下位コントロールを展開します。
   - **日本**：関心のある都道府県を選びます（未選択なら全国）。選んだ都道府県は市区町村まで絞り込めます。
   - **中国大陸**：省 → 地級市 → 半径 を選び、「この都市を追加」を押します。「現在地を使用」も使えます。表の座標は行政区の中心点なので、面積の大きい省・市では半径を広げてください。
   - **その他の国 / 地域**：国を選び、都市を探して 1 クリックで追加します。座標フォームに手入力することもできます。都市リストは人口 10 万以上の都市です。

   登録済みの地域はこのブロックの下にまとめて表示され、いつでも削除できます。
3. **災害の種類としきい値** —— 1 行に 1 災種です。スイッチが通知するかどうか、しきい値がどの強さから通知するかを決めます。
4. **通知とサウンド** —— 通知音やシステム通知を有効にし、音量を調整します。試聴ボタンで確認できます。
5. **データ源** —— 通常は「本番」のまま使います。経路を確認したいときは「サンドボックス」に切り替えます。
6. **テストと診断** —— 2 つのテストボタンはソース形式の電文をローカルで組み立て、実際のパーサーとマッチャーを通します。ネットワーク通信は発生しないため何度でも押せます。下にはソースごとの状態と、AI アシスタントに貼り付けられる診断スナップショットがあります。

アラートが一致すると、通知音とともに、前面ではトースト、背面ではシステム通知が表示され、「警報の記録」に残ります。

## ソースに接続できない場合（中国本土のネットワーク）

中国本土のネットワークでは、データソースに接続できない・更新が止まる・通知が鳴らないことがあります。これらの不具合は現地でしか再現しないため、本プラグインはすべての不具合を **設定 → 災害警報 → テストと診断 → ソース状態** で**見える状態**にし、**AI アシスタント向け**のトラブルシューティング文書（中国語のみ）を用意しています。

> **AI アシスタントに [`TROUBLESHOOTING.zh.md`](./TROUBLESHOOTING.zh.md) を渡し、手順どおりに処理させてください。**
