# dsh-quake-alert · 灾害预警 QuakeAlert

[English](./README.md) · **中文** · [日本語](./README.ja.md)

DeepSeek Harness（DSH）灾害预警插件：你在使用 DSH 时，实时接收**日本**与**全球**的地震、海啸与气象
灾害预警；命中你配置的关注地区与阈值后，以提示音 + 页面 toast + 系统通知提醒。

⚠️ **免责声明（请先阅读）**：预警数据由 [P2PQuake](https://www.p2pquake.net/)、日本气象厅公开 XML 电文、
[EMSC](https://www.seismicportal.eu/)、[USGS](https://earthquake.usgs.gov/) 与
[NOAA](https://www.tsunami.gov/) 提供或转播，均非官方直接推送；紧急地震速报（EEW）的内容与配信品质
无保证。本插件提醒**仅供参考**，避险请以当地官方机构发布为准。插件仅在 DSH 页面开启时工作。

## 功能特性

- **实时推送（日本）**：WebSocket 长连接 P2PQuake，接收地震情报（551）、紧急地震速报 EEW（556）与海啸预报（552）；EEW 从气象厅发布到 P2PQuake 转播通常为数百毫秒级。
- **实时推送（全球）**：WebSocket 长连接 EMSC，接收全球地震。
- **日本气象灾害**：气象厅公开 XML 电文中的泥石流、洪水、大雨与高潮，只在警戒レベル4 以上播报。
- **中国大陆**：Wolfx 转播的中国地震台网地震预警与速报，以及中央气象台的暴雨 / 地质灾害预警信号（橙色及以上）。
- **美国与加拿大**：NWS 的洪水类预警，以及 ECCC 的降雨 / 洪水 / 风暴潮预警，由浏览器直连官方接口查询。
- **全球地震与海啸**：USGS 的全球地震目录与 NOAA 的海啸 CAP 电文，均由 Host 半边轮询。
- **关注地区**：只有一个入口——先选国家 / 地区，再展开该国自己的下级控件。日本 → 都道府县（可选到市区町村）；中国大陆 → 省 → 地级市 + 半径；其他国家 / 地区 → 城市列表或坐标 + 半径。
- **半径用语义档位**：仅本地（约 30 km）/ 本市及周边（约 100 km，新建时的默认）/ 较大范围（约 300 km），也可以直接填公里数。
- **阈值在同一张表里**：一行一个灾种，左边开关决定要不要提醒，右边阈值决定多强才提醒。气象灾害的边界固定，所以只给开关。
- **通知方式**：Web Audio 合成的提示音，音量可调；页面可见时 toast，后台时系统通知。地震与 EEW 的标题带震度。
- **取消 / 解除提醒**：此前提醒过的 EEW 被取消、或海啸预报被解除时，补一条下行音提醒。NWS 的取消消息靠 VTEC 追踪号匹配。
- **静默时段**：每天固定时段内不打扰非关键预警。红色等级默认穿透，可关闭。
- **断线自动重连**：重连间隔逐次延长（1s → 60s 封顶）。P2PQuake 每约 10 分钟强制断线属常态；建连失败与连上后长时间无数据都会被检测并恢复。
- **同一场地震只提醒一次**：同一次地震的多次发布只提醒一次，仅在震度升级时再次提醒；多个机构报同一场地震时，只让先到的源播报。
- **历史记录**：最近 5 天内的 30 条处理记录，只收真的响过的条目与根本没法判定的条目。
- **界面语言**：简体中文 / 繁體中文 / 日本語 / English，在设置里切换、立即生效。来自数据源的文本一律原样透传。
- **配置导出与导入**：把配置导出成 JSON 文件，换机器或换浏览器时导入。导入是整体替换，且导入前会自动备份当前配置。
- **保存在本机**：配置交给 DSH 的机器级存储，跨浏览器、跨机器都在；浏览器 localStorage 作为镜像与回退。
- **源状态**：侧边栏底部一个状态圆点，悬停看逐源明细；设置页「测试与诊断」里另有收到多少增量、失败几次、有没有缺口、最近一次拉取与上游是否停更。
- **数据源切换**：正式源（实时）与沙箱源（回放 2023 年历史，约 30 秒一条）。
- **本地诊断**：两个测试按钮在本地构造源格式电文，走真实的解析与匹配，不发任何网络请求。

## 安装

```sh
# 直接从 GitHub 安装
dsh plugin --profile web add github:MurasakiIzumi/dsh-quake-alert

# 重启 dsh web 使插件生效
```

**升级**：替换包内容后重启 `dsh web`。只涉及 Client 半边（`client/`）的改动刷新页面即可生效；`lib/`
（Host 半边）的任何改动都需要重启。

## 使用

1. 打开 **设置 → 灾害预警**。
2. **关注地区** —— 先选**国家 / 地区**，再展开该国的下级控件：
   - **日本**：点选你关注的都道府县（不选 = 提醒全日本）；选了县之后可再细化到市区町村。
   - **中国大陆**：选省 → 选市 → 选半径 →「添加这个城市」，也可以点「用我的位置」。表里的坐标是行政区中心点，面积特别大的州 / 市请把半径调大。
   - **其他国家 / 地区**：选国家、找到城市后点一下即可添加，也可以手填坐标表单。城市表只收人口 10 万以上的城镇。

   已关注的地区在这个区块下方统一列出，随时可以移除。
3. **灾害类型与阈值** —— 一行一个灾种：开关决定要不要提醒，阈值决定多强才提醒。
4. **通知与声音** —— 开启提示音 / 系统通知，调节音量，用试听按钮验证。
5. **数据源** —— 日常保持「正式」；想验证链路时切「沙箱」。
6. **测试与诊断** —— 两个测试按钮在本地构造源格式电文，走真实的解析与匹配，不发任何网络请求，可反复点击。下面是逐源状态与诊断快照（贴给 AI 排查用）。

收到命中预警时：提示音 + 前台 toast 或后台系统通知，并记录到「最近预警记录」。

## 连不上某个源？（大陆网络）

本插件在**中国大陆网络下**可能遇到某个数据源连不上、数据不更新、或提醒不响。这类问题只在大陆网络下
出现，所以处理方式是把故障变成**可见状态**（**设置 → 灾害预警 → 测试与诊断 → 源状态**），再配一份
**给 AI 读**的排查文档：

> **把 [`TROUBLESHOOTING.zh.md`](./TROUBLESHOOTING.zh.md) 交给你的 AI 助手，让它按步骤处理。**
